# AIda

Telegram-бот, который превращает материалы преподавателя в тренажёр для его
учеников.

Преподаватель заходит, выбирает предмет, загружает свои билеты в `.docx` —
бот разбирает их и собирает тренажёр. Ученик приходит по ссылке-приглашению
и занимается на материалах именно своего преподавателя.

## Возможности

**Преподаватель**
- загрузка билетов `.docx`, разбор в вопросы с ответами;
- отчёт о разборе: сколько принято, что не удалось и почему;
- прохождение своего тренажёра глазами ученика;
- ссылка-приглашение и список присоединившихся учеников.

**Ученик**
- тесты на билетах своего преподавателя, части А и Б;
- проверка ответа и разбор ошибки;
- флеш-карточки: даты, понятия, личности;
- «Спросить» — ответы строго по загруженным материалам.

Предметы настраиваются в `subjects.py`. Сейчас полностью работает
«История Беларуси»; «Русский язык» заведён архитектурно.

## Запуск

Нужен Python 3.11–3.12 (на 3.13+ может не быть готовых пакетов FAISS).

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt   # Windows
# .venv/bin/pip install -r requirements.txt                   # Linux

.venv/Scripts/python.exe -m bot.main
```

Тесты:

```bash
.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
.venv/Scripts/python.exe -m pytest -q
```

На Windows для команд с русским выводом добавляй `PYTHONIOENCODING=utf-8` —
иначе консоль падает на кириллице.

## Настройка

Скопируй `.env.example` в `.env` и заполни. Обязательный минимум:

| Переменная | Что это |
|---|---|
| `TELEGRAM_TOKEN` | токен бота от @BotFather |
| `OPENAI_API_KEY` | ключ OpenAI |
| `ADMIN_IDS` | твой Telegram ID — иначе админские команды открыты всем |

Для базового контента по истории дополнительно нужны `TESTS_SHEET_ID`,
`FLASHCARDS_SHEET_ID`, `TEXTBOOK_DOC_ID` и файл сервисного аккаунта Google,
путь к которому указан в `GOOGLE_CREDENTIALS_PATH`.

## Команды администратора

| Команда | Действие |
|---|---|
| `/update` | перечитать Google Sheets |
| `/reindex` | пересобрать векторную базу (платно) |
| `/reparse` | перегнать все загруженные `.docx` текущей версией парсера |

`/reparse` нужен после доработок парсера: оригиналы файлов сохраняются,
поэтому материалы пересобираются без участия преподавателей.

## Как хранятся данные

```
data/
  subjects/{предмет}/          общий контент предмета
  teachers/{tg_id}/{предмет}/  контент преподавателя
      uploads/                 оригиналы .docx
      tests.json               результат разбора
      manifest.json            что, когда, сколько, версия парсера
  vectorstore/                 векторная база по учебнику
```

Изоляция идёт по `teacher_id` через пути на диске. Ученик видит вопросы
только своего преподавателя.

## Развёртывание

Пример юнита systemd — в `deploy/aida.service`.

```bash
sudo cp deploy/aida.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now aida
sudo journalctl -u aida -f
```
